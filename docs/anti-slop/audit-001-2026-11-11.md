# Audit antislop — audit-001 (2026-11-11)

Target: `design.pen` (9 layar Garasiku konsep Hommie) + `DESIGN.md`.
Mode: AFTER (audit). Temuan tidak diperbaiki sebelum dipilih.

## Design Read

> Reading this as: mobile app manajemen kendaraan untuk pemilik rumah tangga, bahasa visual Hommie (warm neutral, calm, thumb-first), dial ENERGY 1 / RHYTHM 2 / MOTION 1 (diusulkan, belum tertulis di DESIGN.md).

## Temuan

### 1. Ikon motor rusak (HIGH)
- **Rule**: R-35 (verify before deliver) / defect deliverable
- **Lokasi**: komponen VehicleCard + Card "B 9876 KL" di Dashboard dark & light
- **Alasan**: override ikon ke `phosphor/motorcycle` tidak resolve; render tampil sebagai "?" placeholder. Ikon rusak = elemen gagal verifikasi visual.

### 2. `textTertiary` gagal kontras WCAG AA (HIGH)
- **Rule**: R-25
- **Lokasi**: token + semua teks 13px yang memakainya (label section "SERVIS BERKALA BERIKUTNYA"/"DOKUMEN", meta "Abu metalik · 42.310 km", unit "km", "1.0.0", caption lain)
- **Alasan**: light `#8A867F` di atas `bg` = 3.4:1 dan dark `#827E78` di atas `surface` = 4.3:1, dua-duanya di bawah 4.5:1 untuk teks normal; DESIGN.md mengklaim semua kombinasi lulus AA tapi klaim itu salah.

### 3. Loading & error state belum didesain (HIGH)
- **Rule**: R-27
- **Lokasi**: seluruh layar data (dashboard, detail, riwayat servis)
- **Alasan**: UI yang menampilkan data wajib punya empty/loading/error; baru empty state yang ada. Backup/restore (F9) juga butuh state error import (skema tidak valid).

### 4. Dials & Design Read tidak dideklarasikan (MEDIUM)
- **Rule**: R-37 + Block 3 (dials eksplisit)
- **Lokasi**: `DESIGN.md`
- **Alasan**: liveliness bar tidak bisa dipaksakan tanpa dials tertulis; usulan: `Dial: ENERGY 1 / RHYTHM 2 / MOTION 1` (calm, beberapa variasi section, motion micro-feedback saja).

### 5. Ikon = default library look tanpa alasan tertulis (MEDIUM)
- **Rule**: R-04 (icon set dipilih karena recognizable library look)
- **Lokasi**: semua layar
- **Alasan**: hampir semua ikon Lucide; DESIGN.md sendiri menargetkan SF Symbols (iOS) / Material Symbols (Android). Perlu pindah ke Material Symbols Rounded ATAU tulis alasan relevansi tiap ikon di dokumen.

### 6. Radius ikon kontainer inkonsisten (MEDIUM)
- **Rule**: R-11 (radius sebagai alat hierarki, konsisten)
- **Lokasi**: Quick Action Sheet (ikon box radius 999/circle) vs AgendaRow & VehicleCard (radius 12)
- **Alasan**: pill/circle diperbolehkan untuk badge & FAB (fungsional), tapi kontainer ikon harus satu bahasa; saat ini campur.

### 7. Motif identitas Hommie belum menembus semua layar (LOW)
- **Rule**: R-20 / liveliness lever "identity motif"
- **Lokasi**: section header form & settings
- **Alasan**: motif hangat (greeting "Halo, garasimu", status dot) kuat di dashboard, tapi header form/settings masih generik; satu motif yang berulang membuat design "milik" produk ini.

## Lulus pemeriksaan (tidak jadi temuan)

- R-02: tanpa em dash; copy Indonesia spesifik ("Tambah kendaraan pertama"), bukan CTA generik (R-15 PASS)
- R-09: badge fungsional (status riil + label teks, colorblind-safe)
- R-10/R-12/R-13: tanpa glassmorphism berlebih; shadow hanya FAB + sheet (ada alasannya di DESIGN.md)
- R-17/R-18/R-36/R-38: tanpa statistik/testimoni/klaim palsu (memang tidak ada bagian semacam itu)
- R-21: dark-first punya alasan tertulis (OLED), light mode bekerja (terverifikasi via copy)
- R-23: tanpa aset fiktif; foto = placeholder ikon, sesuai instruksi
- R-29: palet = netral hangat + 1 aksen + 3 warna status fungsional
- R-30: bukan kloning Linear/Vercel/dll.
- R-03: target tap ≥ 44–48pt di semua elemen interaktif

## Tindak lanjut (2026-11-11, semua 7 temuan diperbaiki)

1. **Ikon motor** → nama `motorcycle` tidak tersedia, diganti Material Symbols Rounded `two_wheeler`; terverifikasi render di dashboard dark + light.
2. **textTertiary** → token diubah: light `#6E6A63` (5.0:1 di atas `bg`), dark `#9A958D` (5.7:1 di atas `surface`); DESIGN.md disinkronkan.
3. **State** → ditambah layar "Dashboard — Loading (skeleton)" dan "Error State — Dark" (ikon error, pesan, CTA "Coba lagi"); dipandu di DESIGN.md untuk dipakai ulang (gagal muat + gagal import F9).
4. **Dials** → `DESIGN.md` kini memuat Design Read + `Dial: ENERGY 1 / RHYTHM 2 / MOTION 1`.
5. **Ikon set** → 28 ikon diswap ke Material Symbols Rounded (target produksi SF Symbols/Material); alasan relevansi tertulis di baris platform DESIGN.md.
6. **Radius** → ikon box Quick Action Sheet 999 → 12, kini konsisten dengan AgendaRow/VehicleCard.
7. **Motif** → voice "garasimu" diperluas (empty state "Garasimu masih kosong", caption Pengaturan); motif didokumentasikan di DESIGN.md.
